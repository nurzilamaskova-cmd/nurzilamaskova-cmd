## 📊 Проекты

### 🔻 [Анализ воронки и удержания в e-commerce](https://github.com/nurzilamaskova-cmd/ecommerce-funnel-analysis)
Где интернет-магазин теряет пользователей между просмотром, корзиной и покупкой.
**Стек:** ClickHouse, SQL, Tableau
**Результат:** основной отвал на шаге просмотр → корзина (2,69%); из корзины до покупки доходят 31,07% пользователей, медианное время — 4,53 мин.

### 🧪 [A/B-тест нового лендинга](https://github.com/nurzilamaskova-cmd/ab-test-landing-page)
Стоит ли выкатывать новую версию страницы: z-тест, доверительные интервалы, сегментный анализ с поправкой Холма, ARPU/AOV.
**Стек:** Python, pandas, SciPy, statsmodels
**Результат:** конверсия +6,08 п.п. (95% ДИ [5,82; 6,33]), средний чек не изменился. Учебный датасет, цель проекта — методология.

### 🛒 [Поведение пользователей Instacart](https://github.com/nurzilamaskova-cmd/instacart-user-behavior-analysis)
Повторные покупки, retention и размер корзины на 3,4 млн заказов.
**Стек:** Python, pandas, SciPy, Jupyter
**Результат:** 58,97% товарных позиций повторные; самое заметное снижение retention между 5-м и 10-м заказом (88,37% → 53,70%).
